# sdf-skills

Structured Development Flow (sdf): agent skills for requirements and design work.

## Skills

- **sdf-requirements** — Co-write a requirements document: dig into the why, check the as-is, and agree on the experience, scope, and acceptance examples before design.
- **sdf-design** — Co-write a design document: agree on the diff from the as-is, module boundaries, data shape, and how each acceptance example is satisfied before implementation. Follows the project's own design rules.
